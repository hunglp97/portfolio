API and data delivery

The datasets in the catalog are one-off CSV downloads. API access and recurring delivery come with a custom feed; this page describes how that access works once it is set up for you.

Base URL https://api.hlpdata.com/v1. Keys are issued per custom feed.

Request API access

Authentication

Every request carries your API key in the Authorization header with the Bearer scheme.

Authorization: Bearer hlp_live_xxxxxxxxxxxxxxxxxxxxxxxx
Accept: application/json

Endpoints

Responses are JSON in the same schema as the dataset files.

GET/v1/datasetsCatalog index

Metadata for each dataset in your feed: latest collection date, record count and schema definition.

GET/v1/datasets/:id/recordsPaginated records

Filtered, paginated records. Supports limit (default 100, maximum 1000), offset, observed_after and field filters.

GET/v1/datasets/:id/latest-exportFull file

A short-lived pre-signed link to the latest complete snapshot as CSV or Parquet.

Example

Reading records into a Polars data frame in Python:

import requests
import polars as pl

# Authenticated request
headers = {"Authorization": "Bearer hlp_live_YOUR_KEY"}
res = requests.get("https://api.hlpdata.com/v1/datasets/continente-pt/records?limit=1000", headers=headers)
df = pl.DataFrame(res.json()["data"])

# Look at shelf prices and discounts
print(df.select(["product_title", "price", "full_price"]))

Scheduled delivery to your S3 bucket

For large files (500,000 rows and up) a push to your own bucket avoids API rate limits and HTTP timeouts.

  • Files land at s3://your-bucket/hlpdata/<DATASET>/<DATE>/data_file.csv.
  • Each delivery is confirmed by an approved.txt receipt handshake.
  • SHA-256 checksums and a UTF-8 byte-order check come with every file.
