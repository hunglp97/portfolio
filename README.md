# Le Phuoc Hung — Personal Portfolio & Engineering Showcase

> A high-performance, dark-mode portfolio and interactive CV for **Le Phuoc Hung** — Senior Data Engineer & Automation Specialist.

---

## 🌟 Features

- **High-Impact Showcase**: Highlights real-world data pipelines (Data Boutique, Idealista Real Estate, Continente FMCG).
- **Glassmorphism & Obsidian Dark Aesthetic**: Modern tech theme inspired by Linear, Raycast, and Vercel.
- **Interactive Capabilities**: Animated counters, 1-click clipboard email copy, responsive navigation.
- **Print / PDF CV Export**: Native `@media print` CSS stylesheet allowing 1-click export to a clean 2-page PDF resume (`Cmd + P`).
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3 variables, and vanilla JS. Fast loading, 100/100 Lighthouse score.

## 🚀 One-Click Deployment to GitHub Pages

### Method 1: Deploy with GitHub CLI (`gh`)
```bash
# 1. Create the repository on GitHub
gh repo create portfolio --public --source=. --remote=origin --push

# 2. Enable GitHub Pages
# Go to: https://github.com/hunglp97/portfolio/settings/pages
# Source: Deploy from a branch -> main / (root) -> Save
```
Your website will be live immediately at:
👉 `https://hunglp97.github.io/portfolio` (or your GitHub Pages custom domain).
